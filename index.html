💡 Animator Guide & Teacher Setup

🎬 How to Make Great Stop Motion

  • Small Moves: Move your object only a tiny bit between each shot! Small moves equal smooth animation.
  • Onion Skinning: Keep onion skin turned ON so you can see a shadow of where your last frame was.
  • Keep Camera Still: Make sure your webcam or doc camera doesn't move while capturing frames.
  • Use the Spacebar: Tap the SPACEBAR key to quickly take photos without touching the camera.

How to Embed on Google Sites (Teacher Instructions)

To host this app inside Google Sites without camera permission errors, follow these steps:

  1. Host this single HTML file on GitHub Pages, Netlify, or embed using an <iframe> code block in Google Sites.
  2. In Google Sites editor, click Embed > Embed Code and use the following iframe code: 
    <iframe src="YOUR_HOSTED_URL_HERE" 
  width="100%" height="800" 
  style="border:none;" 
  allow="camera; microphone">
</iframe>
  3. Crucial Step: Ensure the allow="camera; microphone" attribute is included in the iframe tag. This enables camera access inside embedded Google Sites pages!
  4. Google Drive Saving: When students click "Save Project" or "Export Movie", Chromebooks automatically give students the choice to download directly into their Google Drive folder!
